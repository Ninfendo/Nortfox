# Security

## Reporting a problem

Please report a security problem privately, through GitHub's form for this repository:

https://github.com/Ninfendo/Nortfox/security/advisories/new

Do not open a public issue or pull request for it. Say what an attacker can do, and how to make it happen. Leave out personal data and real company data: write made-up names and amounts instead.

The maintainer answers in the report, works out a fix with you there, and credits you when the fix is published, unless you ask not to be named.

## Supported versions

None yet. NortFox has no release so far and is not ready for real books. Once releases begin, this section lists the versions that get security fixes.
